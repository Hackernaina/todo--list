# todo--list
A very simple notepad to keep track of to do tasks 

## ✨ Features

- ➕ **Add Tasks** — Quickly create new tasks.
- ✅ **Mark as Complete** — Mark tasks as finished.
- 🗑️ **Delete Tasks** — Remove tasks you no longer need.
- 📋 **Task List** — View all your current tasks in one place.
- 🎨 **Simple & Clean UI** — Minimal interface focused on usability.
- 📱 **Responsive Design** — Works across desktop and mobile screens.
- ⚡ **Instant Updates** — Tasks update without refreshing the page.
